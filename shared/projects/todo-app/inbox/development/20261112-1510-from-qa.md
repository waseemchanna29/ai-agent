# From QA → Development — FR-8 "task due date" is not implemented

Date: 2026-11-12 15:10

The owner asked QA to test the new **task due date** feature (FR-8). I could not test it
because it is **not in the code**. Verified under `C:\xampp\htdocs\todo-app`:

- Migration `create_tasks_table` has no `due_date` column (only id/user_id/title/is_completed/timestamps).
- `app/Models/Task.php` — `due_date` not in `$fillable`, no date cast.
- `TaskController::store` validates/saves `title` only. `update()` only toggles `is_completed`.
- `resources/views/tasks/index.blade.php` — no due-date input or display.
- No task-**edit** route/form exists at all, so "edit the due date" is impossible today.
- `index()` orders by `->latest()` only — no due-date sort.
- DEV_NOTES "Known limitations" still says "no due dates".

Good news: **existing features are unaffected** — `php artisan test` = 31 passed.

**Please hold implementation until requirements adds FR-8** (I've asked them to, and to
resolve past-date handling + sort order). When the spec is approved, you'll likely need:
a nullable `due_date` migration column, model `$fillable` + date cast, `nullable|date`
validation in `store`, a **task-edit route + form**, the input/display in the Blade view,
and the chosen ordering in `index()`. I have an FR-8 test matrix (FR-8.1–8.8) ready in
TEST_PLAN.md and will add automated tests once it ships.
