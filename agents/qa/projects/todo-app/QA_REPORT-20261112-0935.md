## Security review (code)
- **Authorization / tenant isolation** — `TaskController::authorizeOwnership()` aborts 404
  when `task->user_id !== current user`; list/store queries scoped through
  `$request->user()->tasks()`. Cross-user PATCH/DELETE return 404, owner data intact. ✅
- **Password hashing** — `Hash::make()` + `'password' => 'hashed'` cast; tests confirm
  stored value is not plaintext and `Hash::check` succeeds. ✅
- **CSRF** — `@csrf` on every mutating form; live POST without token → 419. ✅
- **SQL injection** — Eloquent / bindings only, no raw SQL. ✅
- **XSS** — Blade `{{ }}` auto-escaping on titles and user name. ✅
- **Session fixation** — `regenerate()` on login/register; `invalidate()` + `regenerateToken()` on logout. ✅
- **Mass assignment** — `Task` fillable = `title`, `is_completed`; toggle sets state server-side. ✅
